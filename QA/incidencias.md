
# Registro de incidencias – C&C Dental Studio

## INC-01 – Error al ingresar al módulo de Pacientes
- **Módulo:** Pacientes
- **Resultado esperado:** Mostrar la pantalla de gestión de pacientes.
- **Resultado obtenido:** El sistema muestra una página de error 404.
- **Estado:** Pendiente de corrección.

## INC-02 – Error al ingresar al módulo de Pagos
- **Módulo:** Pagos
- **Resultado esperado:** Mostrar la pantalla correspondiente a pagos.
- **Resultado obtenido:** El sistema muestra una página de error 404.
- **Estado:** Pendiente de corrección.

## INC-03 – Inconsistencia en los movimientos de inventario
- **Módulo:** Inventario
- **Resultado esperado:** Registrar y mostrar correctamente las entradas y salidas de productos.
- **Resultado obtenido:** El stock se actualizó correctamente, pero el resumen mostró 0 entradas y acumuló las cantidades en salidas. Además, el historial identificó los registros como movimientos genéricos.
- **Estado:** Pendiente de corrección.

## INC-04 – Proveedor no mostrado en el producto
- **Módulo:** Inventario
- **Resultado esperado:** Mostrar el proveedor seleccionado al registrar un producto.
- **Resultado obtenido:** La tarjeta del producto mostró el texto "Sin proveedor".
- **Estado:** Pendiente de investigación y corrección.

## Observaciones generales
Las incidencias fueron identificadas durante las pruebas funcionales del sistema. Se documentan para su revisión por el equipo de desarrollo y posterior validación mediante nuevas pruebas.
